## Лабораторная работа №4

**Объект:** консольное приложение на C++ (`ConsoleApplication1.cpp`), эмулирующее целевую систему (БД/API) со случайными задержками и вероятностью ошибок.
**Цель:** освоить инструменты нагрузочного тестирования, оценить влияние режимов компиляции и параметров нагрузки на метрики (Latency, TPS, P95, P99).

### Выполненные задания
1. **Масштабируемость:** сравнение конфигураций 50 и 500 виртуальных пользователей (потоков).
2. **Перцентили:** расчет метрик P95 и P99 для оценки задержек в «хвосте» распределения (стандарт SLA).
3. **Ramp-up:** реализация ступенчатого запуска потоков с шагом 100 мс для плавного нарастания нагрузки.
4. **Debug vs Release:** сравнение пропускной способности (TPS) и времени отклика в режимах отладки и релиза.

### Сборка и запуск
Проект собирается в **Visual Studio** как консольное приложение C++ (C++14+).
- Режим Debug: `F5`
- Режим Release: `Ctrl + F5`
